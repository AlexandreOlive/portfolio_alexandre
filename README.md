
# Portfólio Profissional — Alexandre Correa de Oliveira

## Sobre o projeto

Este projeto apresenta um portfólio profissional desenvolvido para demonstrar conhecimentos e projetos relacionados à Tecnologia da Informação, com foco em infraestrutura de redes, segurança da informação e desenvolvimento de software.

O site possui layout moderno, responsivo e adaptável a computadores, tablets e smartphones.

## Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, cores, gradientes, animações e responsividade.
- **JavaScript:** interatividade e manipulação dos elementos da página.
- **Google Fonts:** tipografia utilizada no projeto.

## Funcionalidades

- Banner principal com identidade visual tecnológica.
- Menu de navegação.
- Seção de apresentação profissional.
- Cartões de competências com efeitos de gradiente.
- Seção de projetos.
- Área de contato com links.
- Rolagem suave entre as seções.
- Exibição automática do ano atual no rodapé.
- Layout responsivo para diferentes tamanhos de tela.

## Como executar o projeto

1. Baixe ou extraia a pasta do projeto.
2. Abra a pasta no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Clique com o botão direito sobre ele.
5. Selecione **Open with Live Server**, caso tenha essa extensão instalada.

Também é possível abrir o arquivo `index.html` diretamente no navegador.

## Conceitos de programação aplicados

### HTML5

- Estrutura semântica.
- Cabeçalho e navegação.
- Seções de conteúdo.
- Links internos e externos.
- Integração com arquivos CSS e JavaScript.

### CSS3

- Flexbox e Grid.
- Media Queries.
- Gradientes.
- Efeitos de transição.
- Sombras e bordas.
- Responsividade.

### JavaScript

- `addEventListener()`: registra eventos.
- `querySelector()`: seleciona elementos HTML.
- `getElementById()`: localiza elementos pelo ID.
- `textContent`: altera o conteúdo textual.
- `scrollIntoView()`: realiza a rolagem até uma seção.
- `DOMContentLoaded`: aguarda o carregamento do documento HTML.

## Personalização

Para personalizar o portfólio:

- Edite as informações profissionais no `index.html`.
- Altere cores, fontes e efeitos no `css/style.css`.
- Modifique as funcionalidades no `js/port.js`.
- Atualize os links de contato, LinkedIn e GitHub.
- Inclua somente competências e projetos que correspondam à sua experiência real.

## Observações técnicas

Os arquivos CSS e JavaScript são carregados externamente por meio de caminhos relativos:

```html
<link rel="stylesheet" href="./css/style.css">
<script src="./js/port.js" defer></script>
```

A fonte do Google Fonts depende de conexão com a internet.
